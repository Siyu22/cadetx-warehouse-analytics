# CadetX — Heavy Supplier, Inventory & Warehouse Analytics
Programme: Data Analytics & Data Science 12-week applied sprint project
Team: 2 Data Analysts | 1 Data Scientist
Scrum: Weekly sprint rotation of Scrum Master

## Project Goal
Build a unified analytics framework using historical warehouse, supplier, inventory and customer transaction data to analyse product movement, inventory health, warehouse efficiency and supplier performance, plus predictive demand forecasting.

## Dataset
Source: CadetX HeavySuppliersWarehouseDatasets.zip
Tables: branches, customers, inventory_master, invoices, payments, products, purchase_orders_header, purchase_orders_lines, sales_orders_header, sales_orders_lines, stock_ledger, suppliers

## Sprint Roadmap
- Sprint 1 (Week 1): Dataset discovery, ER mapping, data quality scan, draft KPI & hypothesis alignment
- Sprint 2–3: Data cleaning, integration, feature engineering, final data dictionary
- Sprint 4–6: Core product, inventory & warehouse analytics
- Sprint 7–9: Supplier risk, customer segmentation, demand forecasting models
- Sprint 10–12: BI dashboards, anomaly detection, strategy recommendations, final presentation
